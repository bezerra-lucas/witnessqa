# WitnessQA 0.3.1 — private evidence permissions

The public CLI now fixes its process umask to `0077` before executing any
command. Browser workers inherit that restriction, so sanitized evidence stays
non-writable by group and other users even when the invoking shell uses a
collaborative umask such as `0002`.

The native-CI journey test runs the real browser under `umask 0002`, verifies a
complete observation, and checks every referenced evidence file for private
permissions. Harness identity remains bound to the clean release HEAD,
entrypoint digest and `package-lock.json` digest.
